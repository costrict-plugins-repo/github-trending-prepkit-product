# North Star Metric Patterns

## Definition

Single metric that best captures the core value delivered to users. It is a leading indicator of long-term business health, not a direct revenue line.

---

## Criteria Checklist

- [ ] Measures value delivered to users — not revenue directly
- [ ] Leading indicator of long-term retention and growth
- [ ] Influenced by product team actions (not sales, seasonality, or pricing alone)
- [ ] Simple enough to be understood and rallied around org-wide
- [ ] Stable — does not change quarter to quarter

Alignment test: "If this number goes up, does it mean customers are getting more value?"

---

## North Star by Business Type

| Business Type | North Star Example | Why |
|---|---|---|
| Marketplace | Weekly completed transactions | Value = successful matches made |
| SaaS (productivity) | Weekly active tasks completed | Value = work accomplished |
| SaaS (collaboration) | Weekly shared items per team | Value = team-level adoption |
| Content / media | Weekly time well-spent | Value = engagement quality, not quantity |
| E-commerce | Weekly purchases | Value = conversion |
| Developer tools | Weekly active integrations | Value = embedded in workflow |

These are patterns, not prescriptions. Derive from your specific value proposition.

---

## Input Metrics

3–5 metrics that drive the North Star up. Typically decomposed by:

- **Breadth**: how many users reach the core value moment
- **Depth**: how much value each active user gets per session
- **Frequency**: how often users return to extract value
- **Efficiency**: how fast users reach the value moment

---

## Common Mistakes

| Mistake | Why It Fails | Fix |
|---|---|---|
| Revenue as North Star | Lagging, not product-team-actionable | Find the user behavior that drives revenue |
| Metric the product team can't influence | No accountability | Ensure at least 60% of metric movement is product-driven |
| Changing North Star each quarter | Trend analysis breaks, org loses focus | Commit for minimum 12 months before reconsidering |
| North Star = engagement (time-on-site) | Engagement without value = dark pattern risk | Add "well-spent" qualifier or tie to task completion |
